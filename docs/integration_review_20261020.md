# 同學 ZIP 整合檢查（2026-10-20）

來源：`School_Project2-大改(1).zip`。以目前工作區為基礎做三方合併，保留先前的檔案變更偵測及 XMP 刪除部分成功回報。

## 採用的改動

- 主視窗直接進入逐組整理模式，取代舊分組對話框。
- 組內縮圖、保留／丟掉決定、多張保留、鍵盤操作、已看與已調整狀態。
- 預設相似照片模式，可限制只看連拍。
- 依資料夾、待分析張數及整理狀態顯示主要操作按鈕。
- 背景讀取 RAW 內嵌縮圖，沒有內嵌縮圖時沿用原解碼器。
- 分組與待分析張數快取，搜尋、排序與篩選不重新分組。
- 新增狀態邏輯、縮圖、Qt 整合測試，以及可選用的實拍展示工具。

沒有匯入 ZIP 的 `photos.db`、批次結果、Python 快取或 macOS 附屬檔案。兩顆模型權重與目前版本完全相同；推論、評分、分組算法及相似度／連拍門檻未修改。

## 檢查後補強

1. **整理中的照片可能變更。** 確認視窗關閉後、真正刪除前，重新核對所有組員的檔案大小、修改時間及分數，包含原本決定保留的照片。任何變更或無法核對資料庫時，都不刪除。變更時刷新整理結果，要求重新確認。
2. **縮圖可能過期。** 快取另外記錄檔案狀態；每次載入使用不同請求編號，舊背景結果不能覆蓋新圖片。重進整理模式也會清快取。
3. **XMP 部分失敗提示。** 整理模式沿用「已移走照片張數＋未能移走檔案清單」，XMP 失敗不誤算成照片失敗。照片移除失敗時保留其目前預覽。
4. **固定布局撐高視窗。** 在本機 offscreen 檢查中，原版切換整理模式會把 820px 高的視窗撐到超過 1200px。調整縮圖列、預覽最小高度及布局更新順序後，1420×820 的視窗可維持原高度；保留／丟掉按鈕文字也能完整顯示。
5. **XMP 寫入期間主要按鈕可能重新啟用。** 增加明確的寫入狀態，搜尋、統計更新或進度事件不會解除鎖定；寫入完成後恢復原本的控制項狀態。
6. **推薦理由過度解讀技術分。** 改成「技術分最高／技術分較低」，不把曝光、雜訊等綜合技術品質直接稱為清晰度或模糊判斷。

## 執行環境與驗證

本次使用 Windows、Python 3.10.11；測試資料與資料庫放在隔離暫存目錄，未修改現有照片與現有資料庫。

受限環境跑完整測試時，291 項中 287 項通過，4 項因 ExifTool 啟動失敗而未通過。已直接確認：同一個 ExifTool 在受限環境出現 `WinError 623`，正常執行環境則回傳版本 `13.59`；該 4 項移至正常環境重跑，全部通過。因此這 4 項是測試環境造成的假失敗，不是 ZIP 的程式缺陷。

整合相關的 53 項資料庫、分組、縮圖、Qt 背景執行與主控台編碼測試通過。`test_grouping_ui.py` 另在隔離子程序執行 21 項 Qt 情境，涵蓋本次新增的刪除前核對、過期縮圖、視窗高度及 XMP 鎖定。

介面截圖使用合成照片與示範分數，只驗證布局及互動，不代表模型成效或真實 RAW 效能。原作者的 macOS／40 張 RAW 量測保留於 `grouping_ui_delivery.md`，不當作本機重新量測的結果。

最終在正常執行環境重跑完整 unittest discovery：**291 項全部通過，0 失敗、0 錯誤、0 跳過，110 秒**。原始測試紀錄與 JSON 結果保留於本機備份目錄。
