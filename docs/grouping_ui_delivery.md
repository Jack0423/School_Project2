## 展示順序

1. 選擇已分析的照片資料夾，按「相似照片分組」。
2. 點縮圖切換大圖，滾輪縮放與拖曳確認細節。
3. 點「保留／丟掉」或按空白鍵，展示可以同組多留、左側出現「已調整」、底部統計更新。
4. 按 Enter 到下一組，展示已看計數。
5. 展示移到資源回收筒的兩階段確認後取消，避免刪除展示原片。
6. 按 Esc 離開；改權重再進入，展示重新推薦與選擇重設。
