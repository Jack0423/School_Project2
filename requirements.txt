# ── 關於 CUDA 版本 ────────────────────────────────────
# 這裡鎖定 cu128 是有原因的，不能隨意改回較舊的版本。
#
# 本專案使用的 RTX 5070 Ti 是 sm_120 架構。先前安裝的 torch 2.5.1+cu121
# 只編譯到 sm_90，torch.cuda.is_available() 會回 True，但任何實際運算都會拋
#     CUDA error: no kernel image is available for execution on the device
# 導致 GPU 完全無法使用（ai_inference.py 會偵測並自動降級 CPU，程式不會壞）。
#
# 換成 cu128 後 torch.cuda.get_arch_list() 包含 sm_120，GPU 正常運作。
# 升級前後以同一組權重在同一批照片上實測，CPU 結果完全相同
# （AUC 0.9791 / PLCC 0.8315 / SRCC 0.7953），確認版本升級不改變模型行為。
#
# 實測訓練速度（美感模型 5,600 張、batch 32、30 epoch）：
#     CPU  每批 1,192 ms   全程約 104 分鐘
#     GPU  每批   102 ms   全程約   9 分鐘     ← 快 11.7 倍
# GPU 上有 75% 的時間花在資料載入（JPEG 解碼與資料增強都在 CPU），
# 實際 GPU 運算只佔 25%，因此再往上加速的空間有限。
#
# 另外：升級時 pip 會警告 torchaudio 2.5.1+cu121 與新版 torch 不相容。
# 本專案完全沒有使用 torchaudio（全專案 0 處引用），可以忽略。
